# Daily AI Advantage System

一套用于个人长期竞争优势建设的 AI 定时任务 Prompt。

它不是用来总结“今天有多忙”，而是持续检查：你是否在解决重要问题、获得真实反馈、形成可复用资产，并逐步建立判断力、问题所有权、专业声誉与市场入口。

## 4 个定时任务

1. **用户痛点雷达**：每天扫描 GitHub / Reddit / Hacker News / 开发者论坛，寻找真实抱怨、替代需求和付费/迁移信号。
2. **今日高价值动作**：每天早晨识别公司工作与兼职创业的最大不确定性，只选 1 件最重要的事。
3. **每日优势审计**：每天晚上审计今天是否获得现实证据、形成可复用资产和长期优势，并确定明天唯一最重要动作。
4. **长期优势周审计**：每周判断趋势，只输出“继续加码 1 项 / 停止或降级 1 项 / 下周最大验证实验 1 项”。

## 推荐时间

- 08:00 — 用户痛点雷达
- 08:30 — 今日高价值动作
- 22:00 — 每日优势审计
- 周日晚上 — 长期优势周审计

## 核心原则

- 不把“忙”当成价值。
- 不把数据、代码、Prompt、Agent 自动视为护城河。
- 优先真实用户、市场和业务反馈，而不是 AI 内部推演。
- 基础设施必须由重复痛点驱动。
- 每天尽量形成一个真实可见结果。
- 最终目标不是更会用 AI，而是让 AI 放大判断力、现实入口和长期 Power。

## 使用方式

可以直接复制到 ChatGPT Scheduled Tasks、Claude、OpenAI API Agent、自动化工作流或你自己的定时脚本中。建议先连续使用 2 周，再根据真实使用效果修改，而不是先过度设计一套复杂“个人 AI OS”。
